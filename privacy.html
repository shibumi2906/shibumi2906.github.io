Политика конфиденциальности

SurveyArchive — программа для локального поиска геодезических работ в Google Диске. Эта политика описывает текущую предварительную версию приложения и информационный сайт.

Обновлено: 20 октября 2026 года. Контакт разработчика и поддержки: g19732906@gmail.com.

1. Какие данные получает программа

При подключении через Google программа получает OAuth-токены доступа. Пароль Google в SurveyArchive не вводится. Для каталога программа читает названия и идентификаторы файлов и папок, их родительские связи, тип, размер, время изменения, ссылки, версии и сведения, необходимые для проверки доступности и изменений.

Содержимое TXT и PNT в выбранной области загружается для извлечения обозначений точек, кодов, координат и высот. PDF, чертежи и изображения учитываются по метаданным: их содержимое программа не скачивает для разбора. Пользователь может также ввести собственные уточнения названий, сведения о работах и подтверждение системы координат.

2. Зачем нужен Google Drive API

Разрешение https://www.googleapis.com/auth/drive.readonly используется для построения поискового каталога и чтения координатных файлов. Оно позволяет читать доступные аккаунту файлы. Выбор папок в интерфейсе ограничивает действия программы, но не сужает выданное Google разрешение до отдельных папок. Программа не создаёт, не редактирует, не перемещает и не удаляет исходники на Google Диске.

3. Как используются данные

Названия и структура используются для текстового поиска и просмотра каталога. Координаты — для поиска ближайших архивных работ. Метаданные изменений — для обновления каталога по запросу. Новый обход не запускается по расписанию; незавершённая работа может продолжиться после сбоя или следующего запуска.

Данные Google не используются для рекламы, продажи, профилирования или обучения моделей ИИ. Использование и передача данных Google ограничены описанными функциями и требованиями Google API Services User Data Policy, включая Limited Use.

4. Где хранятся данные

Каталог, извлечённые точки, пользовательские уточнения, подтверждения и сведения об обработке хранятся в локальной базе SQLite на компьютере пользователя. Стандартная папка — %LOCALAPPDATA%\SurveyArchive; при специальном запуске может использоваться другая папка. Локальные резервные копии могут содержать эти же данные.

OAuth-токены хранятся через Windows Credential Manager отдельно от базы. Регистрация OAuth-приложения может входить в EXE; она не содержит токенов аккаунта пользователя. В текущей реализации содержимое TXT/PNT обрабатывается в памяти, а результаты извлечения сохраняются в базе. Локальная база и резервные копии не имеют отдельного шифрования на уровне программы: их защищают настройки доступа и шифрования самого компьютера.

5. Передача и доступ третьих лиц

Программа обращается к Google для входа, чтения архива, обновления доступа и отзыва разрешения. Исходные файлы и поисковая база не отправляются на сервер разработчика. Обязательного ИИ-сервиса, облачной аналитики или автоматической отправки диагностических отчётов в программе нет.

Если пользователь сам отправляет материалы по почте поддержки, разработчик получает только отправленные материалы. Не следует присылать пароли, OAuth-токены, ключи и частные исходники без необходимости. При открытии ссылки на исходник браузер обращается к Google Диску.

Этот сайт не добавляет сторонние счётчики, рекламу или формы сбора данных. При размещении на GitHub Pages запросы к сайту обрабатываются GitHub по его политике конфиденциальности. Политика Google применяется к входу и использованию Google Диска.

6. Срок хранения, отключение и удаление

Локальный каталог сохраняется между запусками, пока пользователь не удалит его. Для отключения аккаунта используйте «Отключить Google Диск» в дополнительных настройках: программа удаляет локальные токены и пытается отозвать доступ у Google. Отключение не удаляет сохранённый каталог и резервные копии.

Доступ также можно отозвать в настройках подключений Google-аккаунта. Для удаления локальных данных закройте программу и удалите её папку данных вместе с резервными копиями; если копии или отчёты были перенесены в другие места, удалите их отдельно. Исходные файлы на Google Диске это не удаляет.

7. Обращения и изменения политики

Вопросы о данных, поддержке и удалении материалов, самостоятельно переданных разработчику, направляйте на g19732906@gmail.com. При изменении способов обработки данных эта страница будет обновлена с новой датой.
